## 🚀 Quick Start / Local Preview

You can preview the website locally using the included zero-dependency server:

```bash
# Clone the repository
git clone https://github.com/Peter-ConX/excel-events-outreach.git

# Navigate to the folder
cd excel-events-outreach

# Start local server
npm start
# Server starts at http://localhost:3000
```

Alternatively, open `index.html` directly in any modern web browser or serve via VS Code Live Server / Python:
```bash
python -m http.server 3000
```
